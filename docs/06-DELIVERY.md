# NEXUS — تقرير التسليم النهائي

**التاريخ:** 2026-10-21  
**الإصدار:** 0.1.0  
**البيئة المستهدفة:** Windows 10/11 dev-lite + Docker Compose production-like  
**الحالة:** جاهز للعرض والتسليم الداخلي

## 1. ما تم تسليمه

- منصة NEXUS CYBER DEFENSE كاملة: FastAPI + React 19/TypeScript.
- محركات حقيقية: DNS، TLS، HTTP/Web، Web Vuln، TCP Scanner، PCAP، Log/SOC، NVD 2.0 + CISA KEV.
- طابور مهام متين داخل قاعدة البيانات.
- واجهة عربية/إنجليزية مع RTL/LTR وثيم داكن/فاتح.
- لوحة قيادة، فحوصات، ثغرات، أصول، سطح هجوم، استخبارات، SOC، مختبرات، مساعد ذكي، تقارير، إدارة، ملف شخصي.
- تقارير HTML/JSON/PDF بالعربية الحقيقية.
- سياسة تفويض (RoE) وحاجز خروج `netguard`.
- سجل تدقيق append-only ومترابط بالتجزئة.
- أصول نشر إنتاجية: `docker-compose.yml`، صور API/Worker، Nginx، PostgreSQL.
- بيانات عرض حقيقية مولّدة من المحركات نفسها.

## 5. التشغيل

### Windows

```bat
START-NEXUS.cmd
```

بيانات الدخول المحلية:

- **المالك:** `admin@nexus.local` / كلمة المرور تُسلَّم بشكل منفصل عن المستودع
- **محلل:** `analyst@nexus.local` / كلمة المرور تُسلَّم بشكل منفصل عن المستودع
- **إنشاء حساب جديد:** من صفحة الدخول → «إنشاء حساب جديد». يُحفظ الحساب فورًا بدور viewer، ويمكن للمسؤول منحه الوصول إلى المشاريع من صفحة الإدارة.
- **رابط عام مؤقت من خارج الشبكة:** `PUBLIC-LINK.cmd` (Cloudflare Quick Tunnel). يطبع رابطًا عامًا ويعيد استخدامه عند إعادة التشغيل، أو `PUBLIC-LINK.cmd -Restart` لرابط جديد. يبقى صالحًا ما دام الجهاز والمنصة يعملان؛ لا تشاركه علنًا.

### Docker

```bat
copy .env.production.example .env.production
REM عدّل كل REPLACE_WITH_*
docker compose up -d --build
start http://localhost:8080
```

## 6. حدود صريحة

- **Docker:** غير مثبّت على جهاز التطوير الحالي، لذا تم التحقق من الصياغة فقط، ولم تُشغَّل الحاويات فعليًا هنا.
- **ZAP:** غير مهيّأ محليًا؛ تظهر حالته "غير مهيّأ"، والمحرك الداخلي يعمل.
- **AI Copilot:** معطّل افتراضيًا؛ التحليلات الحتمية تعمل، ولا تُخترع إجابات ذكاء اصطناعي.
- **nmap:** غير مثبّت محليًا؛ الماسح الداخلي نفّذ الفحص الحقيقي. صورة Docker تتضمن nmap.
- **مفتاح NVD:** غير مضبوط؛ عمل NVD بحده العام، وتُخزَّن السجلات فعليًا.
- لا يوجد استغلال مدمر، ولا فحص لأهداف غير مصرّح بها.
