# NEXUS — خارطة الطريق وحالة الإنجاز

> هذه الصفحة تُميّز بين **مُنجَز ومتحقَّق منه** وبين **مُعلَّق باعتماد خارجي**. لا يُسمّى أي بند "مكتملًا" ما لم يُختبر مساره الفعلي.

## 1. المنجز والمتحقَّق منه

| المجال | الحالة | الدليل |
|---|---|---|
| الهوية والصلاحيات | مُنجَز | JWT + Refresh + MFA/TOTP + API Keys + RBAC + عزل المشاريع |
| سياسة التفويض (RoE) | مُنجَز | `netguard` يرفض الخاص/loopback/metadata، ويلتقط `authorization_snapshot` عند إنشاء الفحص |
| طابور المهام | مُنجَز | DB-backed queue: أولويات، CAS claim، Lease/Heartbeat، منع تكرار، إعادة محاولة |
| المحركات الحقيقية | مُنجَز | DNS/TLS/HTTP/WebVuln/TCP/PCAP/Logs/Intel |
| الاستخبارات | مُنجَز | CISA KEV (1754 إدخالًا في العرض) + NVD 2.0 (8 سجلات مخزّنة في العرض) |
| واجهة React | مُنجَز | لوحة القيادة، الفحوصات، الثغرات، الأصول، ASM، SOC، Intel، Labs، Copilot، Reports، Admin، Profile |
| التقارير | مُنجَز | HTML/JSON/PDF (ReportLab + تشكيل عربي حقيقي) |
| i18n | مُنجَز | عربية/إنجليزية + RTL/LTR |
| إنشاء حساب ذاتي | مُنجَز | `/auth/register` + نموذج في الواجهة، دور viewer، تدقيق كامل، حد 5 محاولات/دقيقة |
| الاختبارات | مُنجَز | 45 اختبار backend ناجحًا + `tsc -b` |
| النشر | مُنجَز | Docker Compose + PostgreSQL + API/Worker منفصلين + Nginx |
| بيانات العرض | مُنجَز | مشروع حقيقي، 7 فحوصات مكتملة، 18 نتيجة، 10 أصول، 4 خدمات، 4 تنبيهات، 23 حدثًا |

## 2. يعمل بشرط توفر اعتماد خارجي

| البند | الحالة | الشرط |
|---|---|---|
| OWASP ZAP | غير مهيّأ محليًا | تثبيت ZAP أو تشغيل حاوية ZAP وضبط `NEXUS_ZAP_URL` + `NEXUS_ZAP_API_KEY` |
| Nmap | مهيّأ في صورة Docker، غير مثبّت محليًا | تثبيت Nmap أو استخدام Docker؛ الماسح الداخلي يعمل دائمًا بدون صلاحيات |
| AI Copilot | معطّل افتراضيًا | تعيين `NEXUS_AI_PROVIDER` + المفتاح/النموذج؛ بدون ذلك تعمل التحليلات الحتمية فقط |
| مفتاح NVD | اختياري | بدونه يعمل NVD بحد 5 طلبات/30ث؛ بالمفتاح 50 طلبًا/30ث |
| مزوّدو S3/Kafka/ SIEM | غير مُنفَّذين | خارج نطاق هذا التسليم؛ لا تُعرض كوحدات جاهزة |

## 3. غير مُنجَز أو مدرج لاحقًا

- تنفيذ ثغرات حقيقية أو استغلال مدمر — **مقصود ألا يوجد**، المنصة للتقييم فقط.
- فحص سحابة واسع أو استيراد أصول من CSPM — خارج النطاق الحالي.
- تطبيق جوال — خارج النطاق.
- شهادات امتثال رسمية (ISO/SOC2) — غير مُدّعاة؛ المشروع يوفر ضوابط وسجلات يمكن أن تدعم أدلة التدقيق.

## 4. أولويات ما بعد التسليم

1. ربط مزوّد AI واحد على الأقل (OpenRouter أو Ollama محلي) وتوثيق الميزانية.
2. إضافة تكامل ZAP في Compose عبر `profiles: ["zap"]` عند الحاجة.
3. تصدير أصول/سجلات إلى SIEM عبر Webhook موقّع.
4. اختبارات واجهة إضافية (Vitest) للمسارات الحرجة.
