# NEXUS — المكدس التقني ومحركات الفحص

## 1. المكدس ولماذا

| الطبقة | الاختيار | لماذا هذا بالذات | البدائل المرفوضة ولماذا |
|---|---|---|---|
| API | **FastAPI** (Python 3.11+) | أفضل نظام بيئي للأمن الشبكي (dnspython، httpx، cryptography، dpkt، defusedxml)، تحقق مدخلات صارم عبر Pydantic v2 يقلّل SSRF/Injection، وتوثيق OpenAPI تلقائي | Node/NestJS: مكتبات PCAP/Fingerprinting أضعف. Django: أثقل على async والعمال |
| DB | **SQLAlchemy 2 + Alembic + psycopg** | Postgres للإنتاج، SQLite للتطوير بلا Docker، ترحيلات مُدارة ومسجّلة | ORM خام: لا ترحيلات موثوقة |
| Queue | **طابور داخل قاعدة البيانات** (`jobs`) | لا يحتاج Redis، متين (نجاته من انهيار = نفس نجاة البيانات)، يدعم الأولويات/Lease/Heartbeat/منع التكرار/إعادة المحاولة | Celery/RQ: يحتاج Redis/RabbitMQ + مرافق تشغيل أصعب على Windows |
| Frontend | **React 19 + TypeScript + Vite** | سرعة تطوير، نظام نوع يمنع أخطاء الواجهة، HMR ممتاز | Next.js: نحتاج SPA + API منفصل، لا حاجة SSR |
| Styling | **Tailwind v3.4 + NEXUS UI Kit** (مكوّنات أصلية مبنية بلا نسخ قوالب) | هوية بصرية أصلية + توكنز تصميم مركزية + دعم RTL/LTR بنفس الشيفرة | مكتبات جاهزة: تكرار بصري وقيود تخصيص |
| Charts | **ECharts** | رسوم تفاعلية من بيانات حقيقية، أداء عالٍ مع آلاف النقاط، دعم RTL | Chart.js: أضعف في التفاعل المتقدم |
| State | **TanStack Query + Zustand** | كاش خادم صحيح + حالة واجهة بسيطة | Redux: حِمل زائد بلا مقابل هنا |
| i18n | **i18next** + `dir` ديناميكي | عربية/إنجليزية كاملة مع RTL/LTR | نصوص مضمّنة: غير قابلة للصيانة |
| Reports | **HTML/JSON + ReportLab** (PDF عربي بـ arabic-reshaper + python-bidi) | يعمل على Windows بلا GTK (WeasyPrint يحتاج GTK — مرفوض) | WeasyPrint: يعتمد على مكتبات نظام غير متوفرة افتراضيًا |
| Deployment | **Docker Compose + Nginx + PostgreSQL** | API وعامل منفصلان، واجهة SPA عبر Nginx، قاعدة بيانات مُدارة | نشر يدوي بالكامل: أصعب في التكرار |
| Tests | **pytest + pytest-asyncio** (خلفية) · **Vitest** (واجهة) | اختبار فعلي للمحركات وسياسات الأمان | — |
| CI/CD | **GitHub Actions** | فحص lint + tests + build + فحص أمني | — |

## 2. محركات الفحص الحقيقية

| المحرك | التقنية | ما يفعله فعلًا | يعمل بلا تثبيت؟ | الترخيص/التكلفة |
|---|---|---|---|---|
| DNS | `dnspython` + `crt.sh` (Certificate Transparency) | A/AAAA/CNAME/MX/TXT/NS/SOA/CAA، تحليل SPF/DMARC، اكتشاف نطاقات فرعية من CT وشبكة كلمات محدودة | ✅ | مجاني |
| TLS | `ssl` + `cryptography` | سلسلة الشهادات، SAN، الانتهاء، التوقيع، الحجم، الشهادات الذاتية، إصدارات البروتوكول المتاحة | ✅ | مجاني |
| HTTP/Web | `httpx` (async) | الرؤوس الأمنية، Cookies وسماتها، سلسلة التحويلات، الأخطاء المُفصِحة، robots/sitemap/security.txt، التقاط نماذج POST وغياب رموز CSRF، كشف المحتوى المختلط | ✅ | مجاني |
| Web Vulnerability | محرك داخلي (تحليل + فحوص آمنة) | رؤوس/كوكيز/إفصاح معلومات/TLS، وكشف انعكاس المدخلات (XSS تأملي)، وتوقيعات أخطاء قواعد البيانات (SQLi قائم على الأخطاء) — ضمن "فحص آمن مصرّح" | ✅ | مجاني |
| ZAP | `OWASP ZAP` REST API | زحف + فحص سلبي + نشط (بتصريح منفصل)، استيراد تنبيهات ZAP إلى `findings` مع الأدلة | ❌ يحتاج ZAP (Docker/تثبيت محلي) | Apache-2.0 مجاني |
| Network | `nmap` إن وُجد، وإلا **ماسح TCP connect مدمج** (asyncio) | منافذ مفتوحة، بصمة خدمات أساسية، Banners، TLS على المنافذ، إشارات إعداد خاطئ | جزئيًا (الماسح المدمج يعمل دائمًا) | GPLv2 / مجاني |
| Reachability | `socket`/`dnspython`/`ssl` | DNS lookup/reverse، TCP reachability، زمن الاستجابة | ✅ | مجاني |
| PCAP | `dpkt` | إحصاءات الحزم، البروتوكولات، المتحدثون الأكثر، استعلامات DNS، SNI، منافذ غير معتادة، أنماط اعتمادات نصية (تُنقّح)، استخراج مؤشرات IOC | ✅ | مجاني |
| Log/SOC | محلّل داخلي + محرك قواعد (JSON DSL) | تحليل nginx/apache/syslog/JSON/CSV، تجميع، قواعد كشف، تنبيهات، حوادث | ✅ | مجاني |
| Intel | `NVD 2.0 API` + `CISA KEV` | بحث CVE، CVSS، CWE، مراجع، الثغرات المستغَلّة فعليًا، ربط بالنتائج مع تمييز "مؤكد" عن "مُستنتج" | ✅ | مجاني (مفتاح NVD اختياري يرفع الحد) |
| AI Copilot | محوّل متعدد المزوّدين | شرح/تلخيص/ترتيب/إصلاح/تحليل سجلات + استشهاد بالنتائج الفعلية + ميزانية استخدام | ⚙️ اختياري | حسب المزود (OpenRouter/Ollama/…) |

### التكاليف المتوقعة (تقديرية)
- **بلا أي مفتاح**: 0$ — كل شيء يعمل عدا AI Copilot، وتظهر حالته "غير مهيّأ".
- **Ollama محلي**: 0$ (يحتاج ذاكرة ~6–10GB لنموذج 7B).
- **OpenRouter**: نموذج اقتصادي ≈ 0.1–1$ لكل مليون توكن دخل. مع ميزانية افتراضية 500K توكن/شهر ≈ **أقل من 1$**. الميزانية تُفرض في الكود وتُعرض في الواجهة.
- **NVD API key**: مجاني بالكامل (يرفع الحد من 5 إلى 50 طلبًا/30ث).

## 3. سياسة الدقة في النتائج (Result Integrity)

1. الثقة (`confidence`) تُسجَّل لكل نتيجة: `certain` / `firm` / `tentative`.
2. الحالة (`status`) مستقلة عن الثقة: `open`/`confirmed`/`fixed`/`accepted_risk`/`false_positive`.
3. ربط CVE يرتدي وسمًا: `exact` (رقم مؤكد) أو `inferred` (استنتاج من إصدار منتج) — والثاني **لا يُعرض أبدًا** كتأثر مؤكد.
4. كل مرحلة في الفحص تُنتج `events` قابلة للعرض، وكل نتيجة تحمل `engine` + `engine_version`.
5. عند نقص الأدلة، يذكر Copilot نقص الأدلة صراحةً بدل الجزم.
